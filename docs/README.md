# Postomat – Doku

Postomat ist ein Werkzeug, mit dem jedes Attraktor-Mitglied ohne Social-Media-Kenntnisse einen Post oder ein Event anstoßen kann. Das Medienteam muss am Ende nur noch freigeben.
