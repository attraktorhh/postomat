# Styleguide (abgeleitet)

Abgeleitet aus den letzten Beiträgen von `@attraktor_org`, `blog.attraktor.org` und Meetup (Stand 23.11.2026). Es gibt noch keinen offiziellen Styleguide. Dieses Dokument ist der Startpunkt dafür.

## Bilder: Banner-Vorlage

Die meisten Instagram-Posts sind **gestaltete Grafiken**, keine reinen Fotos. Postomat erzeugt diese Vorlage automatisch aus dem Foto eines Mitglieds.

```
+------------------------------------------+
|                                          |
|  Foto (füllt die Fläche)                 |  optional: Sticker "COME MEET US"
|                                          |
|  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  |  Band mit geschwungener Oberkante,
|  TITEL IN GROSSBUCHSTABEN     attraktor  |  Farbe je nach Anlass
|  Uhr: Datum | Uhrzeit       e.V. Hamburg |  Logo (Pinselschrift) rechts
|  Pin: Attraktor e.V. Eschelsweg 4        |
+------------------------------------------+
```

Im Bild stehen vor Datum und Ort ein Uhr- und ein Pin-Symbol. Beispiel: „Sonntag, den 18.10.26 | 11 – 13 Uhr“ und „Attraktor e.V. Eschelsweg 4, 22767 Hamburg“.

| Farbe    | Beispiel                       |
| -------- | ------------------------------ |
| Mint     | Lötworkshop auf der Code Week  |
| Blau     | „Bald ist wieder Maker Faire!“ |
| Rot      | Muttertags-Lötworkshop         |
| Hellblau | Grundfarbe der Illustrationen  |

**Bleibt Handarbeit:** illustrierte Kampagnen-Posts (die Figur mit blauer Kapuze, Linkshändertag, Cosplay) und Reels mit Musik. Postomat kann sie einplanen, gestaltet sie aber nicht.

**Noch nötig:** das Logo als Datei (SVG oder großes PNG) und die Schrift der Titel.

## Texte

**Anrede:** immer „du“ bzw. „ihr“. Gendern mit Sternchen kommt vor („Mitglieder*innen“).

**Sprache:** bisher nur Deutsch. **Neu: jeder Text auf Deutsch und Englisch.**

| Kanal     | Wie die zwei Sprachen erscheinen                       |
| --------- | ------------------------------------------------------ |
| Instagram | Englische Kurzfassung unter dem deutschen Text, mit 🇬🇧 |
| Mastodon  | Deutscher Post, englische Fassung als Antwort          |
| Website   | Ein Beitrag mit englischem Abschnitt                   |
| Meetup    | Titel „Deutsch / English“, Beschreibung beide          |
| Wiki      | Deutsch                                                |

### Formel für Instagram

1. **Aufhänger** als Frage oder Ausruf: „Du wärst gerne kreativ, weißt aber nicht, wie und wo du anfangen sollst…“, „</> Es ist wieder Code Week!“
2. **✨ Text** mit 2–3 kurzen Sätzen
3. **🕓 Datum** im Format „Sonntag, den 18.10.26 | 11 – 13 Uhr“ und **📍 Ort**
4. **🇬🇧 English** als Kurzfassung
5. Wenige Hashtags, Standort „Hamburg“

### Formel für Meetup

Emoji als Abschnittsmarker, Stichpunkte, am Ende Adresse („Attraktor e.V., Eschelsweg 4, 1. Stock, 22767 Hamburg“) mit ÖPNV-Hinweis und Kontakt.

### Formel für die Website

Titelbild, kurze Einleitung, Block „Wo: / Wann: / Was:“, Beschreibung, Meetup-Link, Kategorie „Termine“ (Workshops zusätzlich „Workshops“).
